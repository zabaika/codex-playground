# LinkedIn MCP maintenance

Before editing, updating, repairing or reinstalling this plugin, read and apply
[Local update contract](README.md#local-update-contract). That section owns the
user's restrictions, update sequence, scenarios and acceptance checks. Do not
duplicate or weaken its requirements here.

Edit this repository source, never the installed cache. Resolve conflicts with
the user before changing the affected behavior. Run the contract checks and
scenario review before reinstalling, then verify complete source/install parity
using the installed root returned by Codex. Stop the update on a failed check;
report unverified runtime behavior explicitly.
