# Job Search System: Capability Coverage

This document is the implementation coverage register for the canonical plans in `Job/job-search-skills`.

It intentionally ignores `job-search-skills-design-backup.md`: that file is a non-canonical reserve copy and must not be used as a source of requirements.

## Coverage Rule

Every planned capability from the canonical plan set must have at least one of these statuses:

- `backend/API/CLI implemented`
- `skill wrapper implemented`
- `explicitly deferred to stage3-backlog.md`

If a capability is present in the canonical plans but absent from this file, from `skills/jss-*`, from `tools/job-search-system`, and from `stage3-backlog.md`, treat it as a planning bug. Every row with `explicitly deferred to stage3-backlog.md` must also name its numbered Stage 3 implementation group in the evidence column.
